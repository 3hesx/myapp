# 工作生活 · 本地记录工具（worklife）

一个**纯本地、零依赖、免联网**的个人「工作 + 生活」一体化记录工具。把散落在各处的待办、灵感、训练、饮食、游戏记录收进一个页面，数据只存在你自己的浏览器里。

> 仓库地址：https://github.com/3hesx/myapp

---

## 1. 项目解决什么问题

很多人同时有「工作」和「生活」两条线，但记录工具要么太重（要注册、要联网、要同步服务器），要么太碎（便签、备忘录、Excel 各记各的）。本项目面向**只想给自己用的个人用户**，解决三件事：

- **集中**：工作（自媒体 / 开发 / 咨询）和生活（健身 / 饮食 / 游戏）在一个页面里，左侧九宫格切换，不用在多个 App 之间跳。
- **私密 / 离线**：不注册、不联网、不发任何远程请求，数据只落在本地浏览器 `localStorage`，断网也能用。
- **零门槛**：原生 HTML/CSS/JS，无框架、无构建、无 CDN。双击 `index.html` 就能用，不用装 Node、不用起服务、不用命令行。

> 明确不做（范围外，不是遗漏）：登录/账号、云端同步、手机适配与安装包、提醒通知、全局搜索、拖拽排序、附件上传、AI 功能、多级页面。

## 2. 主要功能

| 模块（左侧入口） | 功能 |
|---|---|
| **首页总览** | 一眼看清今天：可勾选显示的各模块摘要卡片（自媒体 / 开发 / 咨询 / 健身 / 饮食 / 游戏）。 |
| **今日计划** | 按时间安排当天事项；支持「从其他模块加入今天」（加入的是**快照**，之后改/删原条目不影响今日事项）。 |
| **自媒体** | 选题 → 发布记录 → 数据记录。数据记录页含**汇总卡片**（总阅读 / 总互动 / 总涨粉 / 平均阅读）和**手写内联 SVG 分组柱状图**（阅读 / 互动 / 涨粉对比），纯 SVG，不引图表库。 |
| **开发工作** | 项目、任务/Bug、速记三类；无项目时「新增任务」会平滑引导先建项目并自动衔接。 |
| **咨询工作** | 客户、咨询纪要、待跟进；客户行可删除并支持撤销。 |
| **健身计划** | 周计划、训练日志（动作·部位·组数·次数·重量）、体重趋势；并提供**月历视图**展示每日训练。 |
| **饮食计划** | 按天记四餐（早/午/晚/加餐）+ 饮水 + 小结；并提供**月历视图**展示每日餐次与饮水。 |
| **游戏娱乐** | 想玩清单、游戏时长记录、评价。 |
| **数据与设置** | 深浅色主题、每周起始日、首页卡片开关；导出 JSON 备份、从文件导入恢复、清空模块、全部重置。 |

通用能力：

- **即时自动保存 + 顶部「已自动保存 ✓」指示**：输入回车、改下拉框、点勾选即落盘，无保存按钮（历史锁定决策）。
- **历史只读**：过去的日期不可补记或改动。
- **导出 / 导入备份**：导出 `worklife-backup-YYYY-MM-DD.json`；导入前显示各模块条目数并二次确认，**导入会覆盖当前全部数据**。
- **编辑交互**：右侧抽屉，`Esc` 或点遮罩关闭，`Enter` 提交；删单条给一次撤销，清空 / 覆盖 / 重置才弹二次确认。

## 3. 安装方法

### 3.1 作为使用者（无安装）

1. 把整个 `worklife/` 文件夹固定放在一个位置（**不要移动或重命名**，否则浏览器按路径隔离会读不到原数据）。
2. 用 **Chrome 或 Edge 桌面版**双击 `worklife/index.html` 打开即可。

不需要启动服务、不需要 npm、不引任何 CDN；断网也能正常使用。

### 3.2 作为开发者（运行自动化测试，可选）

仓库自带基于真实浏览器的测试（`tests/`），需本机具备：

- **Node.js 18+**（仓库用 22.x 验证）
- 本机已安装 **Chrome 或 Edge**（测试通过 puppeteer-core 驱动本机浏览器，零额外安装）

运行全部测试：

```bash
node tests/run-all.js
```

测试覆盖 PRD 验收点（阶段 0–6，含 v1.1 的 G1–G7）。各阶段也可单独运行，例如 `node tests/stage6.test.js`。

## 4. 使用方法

1. 打开 `worklife/index.html`（Chrome / Edge 桌面版）。
2. 左侧选择模块，右侧抽屉新增 / 编辑条目；**改完即保存**，顶部闪一下「已自动保存 ✓」。
3. 把常用事项用「今日计划 → 从其他模块加入今天」汇总到当天。
4. 定期备份：左侧栏底部「立即备份」，或在「数据与设置 → 导出 JSON 备份」下载备份文件，存到本机或别处。
5. 换电脑 / 误清缓存后，用「数据与设置 → 从文件导入」选该 JSON 恢复（导入前会先确认覆盖）。

偏好设置（主题、每周起始日、首页卡片）与模块数据一起存、一起导出。

## 5. 输入输出示例

本工具是浏览器本地应用，没有命令行输入/输出。下面的「输入」指你在界面上的操作，「输出」指落盘到 `localStorage` 的数据，以及可下载的备份文件。

### 5.1 输入：在「开发工作」新增一条任务

在「开发工作 → 任务」抽屉中填写并提交：

| 字段 | 值 |
|---|---|
| 项目 | 个人网站 |
| 标题 | 加一个深色模式切换 |
| 类型 | task |
| 优先级 | high |
| 状态 | todo |

### 5.2 输出：落盘到 `localStorage["worklife:v1"]`（节选）

写入的是一整个状态对象，上述操作会反映到 `data.dev.tasks` 里新增一条：

```json
{
  "schemaVersion": 1,
  "settings": { "theme": "dark", "homeCards": ["media","dev","consult","fitness","diet","games"], "weekStartsOn": 1, "lastExportedAt": null },
  "data": {
    "memos": [],
    "today": [],
    "media":   { "topics": [], "posts": [], "metrics": [], "ideas": [] },
    "dev": {
      "projects": [{ "id": "p1", "name": "个人网站", "status": "active", "note": "" }],
      "tasks":    [{ "id": "t1", "projectId": "p1", "title": "加一个深色模式切换", "type": "task", "priority": "high", "status": "todo" }],
      "snippets": []
    },
    "consult":   { "clients": [], "sessions": [], "followups": [] },
    "fitness":   { "weekPlan": { "1":"","2":"","3":"","4":"","5":"","6":"","7":"" }, "exercises": [], "workouts": [], "body": [] },
    "diet":      { "days": {}, "commonFoods": [] },
    "games":     { "list": [], "sessions": [] }
  }
}
```

### 5.3 输出：导出备份文件 `worklife-backup-2026-11-12.json`

点击导出后下载的文件结构（与内部状态一致，多了一个导出元信息头）：

```json
{
  "app": "worklife-local",
  "schemaVersion": 1,
  "exportedAt": "2026-11-12T...",
  "settings": { "theme": "dark", "homeCards": ["media","dev","consult","fitness","diet","games"], "weekStartsOn": 1, "lastExportedAt": "2026-11-12T..." },
  "data": { "memos": [], "today": [], "media": {...}, "dev": {...}, "consult": {...}, "fitness": {...}, "diet": {...}, "games": {...} }
}
```

导入时工具会校验 `app === "worklife-local"` 且 `schemaVersion === 1`，并**先显示各模块条目数、二次确认后整体覆盖**当前数据。

### 5.4 其它模块的数据形态（与界面字段一一对应）

- **自媒体发布记录** `media.posts[]`：`{ "id", "topicId", "date", "platform", "title", "link" }`
- **健身训练** `fitness.workouts[]`：`{ "id", "date", "exerciseId", "sets", "reps", "weight" }`
- **饮食某天** `diet.days["YYYY-MM-DD"]`：`{ "breakfast": [], "lunch": [], "dinner": [], "snack": [], "water": 0, "note": "" }`（四餐数组存食物文本，单位杯计入 `water`）
- **游戏时长** `games.sessions[]`：记录某游戏某次游玩的时长与评价
