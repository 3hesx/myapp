# 工作生活 · 本地记录工具（第一版）

一个只给自己用的本地小工具：把工作（自媒体、开发、咨询）和生活（健身、饮食、游戏）收在一个页面里。不需要注册、不需要联网、不需要装任何东西。

## 怎么打开

双击 `worklife/index.html`，用 **Chrome 或 Edge 桌面版**打开即可。

- 不用启动服务、不用命令行、不用 npm，也不引任何 CDN。
- 第一版只承诺 Chrome / Edge 桌面版；手机浏览器不保证可用。
- 断网也能正常用，页面不会发任何远程请求。

## 数据存在哪里（重要）

**数据只存在这台电脑的这个浏览器里**（浏览器本地存储 `localStorage`，键为 `worklife:v1`），不会上传到任何地方。

请务必注意：

1. **不要移动或重命名 `worklife/` 文件夹**。浏览器本地存储是按页面文件路径隔离的，路径变了就读不到原来的数据。请把它固定放在一个位置，建议就用当前这个路径。
2. **清理浏览器缓存 / 网站数据、换浏览器、换电脑，数据都可能读不到**。
3. 所以请**定期导出备份**：左侧栏底部「立即备份」，或「数据与设置 → 导出 JSON 备份」。会下载一个 `worklife-backup-YYYY-MM-DD.json` 文件，把它留在本机或复制到别处。
4. 换电脑或误清缓存后，用「数据与设置 → 从文件导入」选这个 JSON 恢复。导入前会先显示各模块条目数并让你确认覆盖，**导入会覆盖当前全部数据**。

## 日常怎么用

- 左侧九个入口：首页总览 / 今日计划 / 自媒体 / 开发工作 / 咨询工作 / 健身计划 / 饮食计划 / 游戏娱乐 / 数据与设置。
- 改完就生效，**没有保存按钮**：输入后回车、改完下拉框、点完勾选，数据立刻写入本机，并闪一下「已保存」。
- 编辑用右侧抽屉：`Esc` 或点遮罩关闭，`Enter` 提交。
- 删单条会立刻移除并给一次「撤销」机会；清空模块、覆盖导入、全部重置才会弹二次确认。
- 「今日计划 → 从其他模块加入今天」是唯一跨模块联动。加入的是**快照**：之后改或删原条目，不影响已加入的事项。
- 过去的日期只读，不能补记或改动。

## 偏好

「数据与设置」里可以切换深浅色、设置每周起始日、勾选首页显示哪几张摘要卡片。这些偏好和模块数据一起存、一起导出。

## 第一版不包含

登录/账号、联网与同步、手机适配与安装包、提醒通知、全局搜索、拖拽排序、附件上传、复杂图表、卡路里计算、AI 功能、多级页面。这些是明确的范围外，不是遗漏。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 唯一页面，双击打开 |
| `styles.css` | 全部样式 |
| `js/core.js` | 公共函数、状态枚举、日期处理 |
| `js/store.js` | 数据读写、导出/导入/重置（唯一写入口） |
| `js/ui.js` | 抽屉、确认框、轻提示、空状态 |
| `js/shell.js` | 导航壳层与页面切换 |
| `js/page-*.js` | 九个页面，各一个文件 |
| `js/app.js` | 启动 |

开发依据与验收记录见上层目录的 `PRD.md`、`docs/开发计划.md`、`docs/验收记录.md`，自动化测试在 `tests/`。
