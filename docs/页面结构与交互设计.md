# 页面结构与交互设计（第一版）

> 状态：待确认
> 阶段：页面结构与交互设计
> 本阶段只产出设计说明与线框，未编写任何应用代码、未创建项目
> 依据：已确认的《第一版范围》

---

## 0. 设计原则

1. **单窗口、不跳页**：所有模块在同一个页面里切换，不刷新、不新开标签页。编辑一律用右侧抽屉，不进入二级页面。
2. **自动保存**：没有「保存」按钮。任何改动立刻写入本机，右下角给一个一闪而过的「已保存」提示。
3. **一个模块一个样子**：页面骨架按场景分三类（主从型 / 分页签型 / 按日记录型），不复用同一个待办清单模板。
4. **只读摘要在首页**：首页的模块卡片只展示数字和状态，点卡片才进模块；唯一例外是首页可以直接勾选今日计划。
5. **危险操作才打断**：删除单条用轻提示 + 撤销；清空、覆盖导入、全部重置才用模态二次确认。
6. **离线即时**：没有加载态、没有骨架屏、没有网络错误提示，本地数据读出来就能用。

## 1. 全局壳层

### 1.1 布局

```
┌──────────────┬────────────────────────────────────────────┐
│              │  页面标题栏（标题 + 页面级主操作 + 日期）      │
│   左侧导航    ├────────────────────────────────────────────┤
│   固定 200px  │                                            │
│              │           主内容区（可滚动）                 │
│  9 个入口     │                                            │
│  分组         │                                            │
│              │                                            │
│              │                              ┌──────────┐  │
│  底部：       │                              │ 右侧抽屉  │  │
│  存储状态     │                              │ （编辑时）│  │
│  备份入口     │                              └──────────┘  │
└──────────────┴────────────────────────────────────────────┘
```

- 侧栏固定宽度，主内容区自适应；窗口再窄也只保证桌面浏览器（不做移动端断点）。
- 右侧抽屉宽约 360px，从右滑入，背后主内容变暗但仍可见；点遮罩或按 Esc 关闭。
- 顶部不放全局搜索、不放面包屑（第一版不做）。

### 1.2 侧栏导航

分三组，视觉上用细分隔线区分：

| 分组 | 入口 |
|---|---|
| 总览与日程 | 首页总览、今日计划 |
| 工作 | 自媒体、开发工作、咨询工作 |
| 生活 | 健身计划、饮食计划、游戏娱乐 |
| 底部单独区 | 数据与设置 |

- 当前页高亮（左侧色条 + 加粗）。
- 侧栏顶部：当天日期与一句问候。
- 侧栏底部：一行小字「数据已保存在本机」+「立即备份」文字按钮；有未备份改动时小字变为提醒色。
- 「数据与设置」放在最底部并弱化，避免日常误点。

### 1.3 页面标题栏

- 左：页面名 + 一句该页说明（例如「自媒体 · 从选题到发布数据」）。
- 右：该页主操作按钮（「+ 新增选题」「+ 新增任务」等），以及该页需要的日期切换/视图切换控件。
- 主操作每页只有一个，避免一排按钮。

### 1.4 通用容器

- **卡片**：用于首页摘要、概览数字、设置分区。
- **列表行**：用于各类条目，行内直接放勾选框、状态标签、来源标签和删除图标。
- **抽屉**：用于新建/编辑表单。新建时抽屉标题为「新增…」，编辑时为「编辑…」。
- **标签页（Tab）**：用于同一模块内几种不同性质的内容切换，切换时保留各自滚动位置。

## 2. 各页面结构与交互

### 2.1 首页总览

| 区块 | 内容 | 交互 |
|---|---|---|
| 欢迎条 | 日期、星期、今日完成度（进度条 + 已完成/总数） | 只读 |
| 今日计划摘要 | 今天前 5 条，含时间、标题、模块标签、勾选框 | 可直接勾选完成；「查看全部」跳今日计划 |
| 快速备忘 | 单行输入框 + 最近 5 条备忘 | 回车即存；每条可勾选完成、删除；不分类、不设日期 |
| 模块摘要卡片 ×6 | 自媒体 / 开发 / 咨询 / 健身 / 饮食 / 游戏 | 每张显示 1~2 个关键数 + 最后更新；整卡可点进模块 |

六张卡片的关键数：

- 自媒体：待发布数、本月已发数
- 开发工作：进行中项目数、未完成任务数
- 咨询工作：待跟进数、本月咨询次数
- 健身计划：今日应练内容、本周已练次数
- 饮食计划：今日已记录餐次、饮水杯数
- 游戏娱乐：在玩数量、本周游戏时长

空状态：某个模块还没数据时，卡片不显示 0，改显示一句引导 +「去添加」。

### 2.2 今日计划

- **日期条**：前一天 / 今天 / 后一天 + 日历回到今天；显示当日完成度。
- **时间轴列表**：按时间升序，每行 = 时间段 + 标题 + 来源模块标签 + 完成勾选 + 删除。
- **新增**：行内输入（时间 + 标题 + 模块标签），回车加入，即时重排。
- **跨模块入口**：「从其他模块加入今天」打开一个抽屉，按模块分组列出可加入的条目，勾选后一次性写入今天，并带上来源标签。
- **筛选**：按模块标签筛选；默认全部。
- **当日小结**：底部一行「完成 X / 共 Y 条」。
- **历史**：日期条切到过去日期即为只读回看；过去的日期不提供新增与勾选（避免误改历史），需要改时先切回该日期的编辑态，第一版简化为历史只读。

### 2.3 自媒体（分页签型）

三个 Tab：**选题库 / 发布记录 / 数据记录**

- 选题库：顶部状态筛选（想法 → 撰写中 → 待发 → 已发），列表行含标题、平台、状态标签、目标发布日期；点行开抽屉编辑；状态可用行内下拉直接改。
- 发布记录：按月份倒序的列表，字段为日期、平台、标题、链接；新增时可「由选题一键转为已发布」，自动带到选题信息。
- 数据记录：在已发布条目下填写阅读/播放、互动、涨粉等数字，一行一个指标；只记录，不做图表。
- 灵感速记：选题库页右下角一个小面板，随手记句子，可「转为选题」。

### 2.4 开发工作（主从型）

- 左列：项目列表（项目名 + 状态 + 未完成任务数），可新增、重命名、归档。
- 右列：选中项目的任务与 Bug，按状态分组；字段为标题、类型（任务/Bug）、优先级、状态；行内改状态，点行开抽屉编辑。
- 第三个 Tab「速记本」：代码片段与常用命令，纯文本条目 + 语言/用途标签，一键复制。
- 项目删除时提示「该项目下的 N 条任务也会删除」，需二次确认。

### 2.5 咨询工作（分页签型）

顶部统计条：本月咨询次数、累计时长。

三个 Tab：**客户档案 / 咨询记录 / 待跟进**

- 客户档案：列表 + 抽屉，字段为名称、备注、联系方式（仅本机保存）。
- 咨询记录：按日期倒序，字段为客户、日期、主题、时长、结论纪要；新增时从客户档案选择，自动带入。
- 待跟进：每条含客户、下次时间、事项；到期或逾期的条目在顶部置顶并标记；可「加入今天」。
- 客户被删除时，其历史记录保留但标注「已删除客户」，不级联删除（避免丢历史）。

### 2.6 健身计划（按日记录型 + 分页签）

三个 Tab：**本周计划 / 训练记录 / 身体数据**

- 本周计划：周一到周日七格，每格填当天训练部位/内容；点格子直接编辑。
- 训练记录：选日期 → 选动作（来自动作库）→ 逐组填次数与重量；一次训练可含多个动作；动作库可自行增删动作名与部位。
- 身体数据：日期 + 体重（+ 可选体脂），上方一条迷你趋势线（纯展示，不放大成图表页）。
- 首页「今日应练」读取本周计划中今天那一格。

### 2.7 饮食计划（按日记录型）

- 顶部日期切换（默认今天）。
- 四个餐次区块：早餐 / 午餐 / 晚餐 / 加餐，每块是若干条食物行（名称 + 大致份量），可就地新增、删除。
- 常用食物：右侧一列快捷 chips，点一下直接加入当前选中的餐次。
- 饮水计数器：杯型图标 + 「+ / −」，显示今日杯数。
- 每日小结：一行备注（例如「外食偏油」），自动保存。
- 不计算卡路里、不接营养库（第一版不做）。

### 2.8 游戏娱乐（分页签型）

顶部统计条：本周游戏时长。

两个 Tab：**游戏清单 / 时长记录**

- 游戏清单：状态筛选（想玩 / 在玩 / 通关 / 弃坑），字段为名称、平台、状态、评分（星或 1~5）、一句短评；行内改状态。
- 时长记录：日期 + 游戏 + 时长（分钟或小时）+ 备注；新增时从清单选择游戏。
- 评分与短评在清单抽屉里编辑。

### 2.9 数据与设置

四个分区，纵向排列：

| 分区 | 内容 |
|---|---|
| 数据概览 | 各模块条目数、最早记录日期、当前占用量估算 |
| 备份与恢复 | 「导出全部数据」（下载一个 JSON 文件）、「从文件导入」（选文件 → 预览条目数 → 确认覆盖） |
| 清理 | 按模块清空、全部重置；均需模态二次确认，全部重置要求输入确认词 |
| 偏好 | 界面深浅色、首页显示哪些摘要卡片、每周起始日（周一/周日） |
| 存储说明 | 一句大白话解释数据存在这台电脑的浏览器里、清缓存会丢、建议定期导出 |

导入流程必须显式警告「导入会覆盖当前全部数据」并展示待导入文件的条目数，确认后才执行。

## 3. 通用交互规范

### 3.1 增删改查

| 动作 | 方式 |
|---|---|
| 新增 | 页面主操作按钮 → 抽屉或行内输入；Enter 提交 |
| 查看/编辑 | 点条目 → 右侧抽屉；Esc 或点遮罩关闭 |
| 删除（单条） | 行内删除图标 → 立即移除 + 底部「已删除 · 撤销」（约 5 秒） |
| 删除（级联/清空/重置） | 模态二次确认，说明影响范围 |
| 状态切换 | 行内下拉或勾选框，一键生效 |
| 排序 | 各页固定排序规则（时间倒序 / 状态分组 / 自定义顺序），第一版不提供手动排序 |

### 3.2 保存与反馈

- 所有写入即时落盘，无「保存」按钮。
- 反馈分三级：
  - 轻：右下角 Toast「已保存」「已删除 · 撤销」，2~3 秒消失。
  - 中：表单校验不通过时，字段下方红字内联提示（例如日期为空、时长非数字）。
  - 重：不可逆操作用模态框，标题写清后果，主按钮用警示色。
- 不显示加载动画、不显示网络错误。

### 3.3 空状态

每个列表首次为空时，显示一句场景化引导 + 该页主操作按钮（例如「还没有选题，先记一个想法」）。不显示空白页或 0。

### 3.4 键盘

- Enter：提交当前输入 / 确认抽屉。
- Esc：关闭抽屉、取消行内编辑、关闭模态框。
- 不做全局快捷键、不做命令面板。

### 3.5 危险操作

- 单条删除：可撤销，不打断。
- 项目删除（含子任务）、按模块清空、覆盖导入、全部重置：模态确认。
- 全部重置额外要求输入「重置」二字才启用按钮。

## 4. 跨模块数据流

第一版只保留一条联动，避免过度耦合：

```
模块内条目 ──「加入今天」──▶ 今日计划（生成一条带来源标签的事项）
```

- 生成的是**快照**：写入今天后与源条目不再同步，源条目改名或删除不影响已生成的今日事项。
- 首页摘要卡片是**只读聚合**，在首页不能改模块数据。
- 首页唯一可写：勾选今日计划、新增/勾选快速备忘。
- 今日计划按日期归档，历史只读。

---

## 5. 数据写入与备份流程

- 每次增删改后立即写入本机浏览器存储；写入失败（例如空间不足）给出明确提示并建议导出备份。
- 导出：生成一个带日期的 JSON 文件下载到本机，包含全部模块数据与偏好设置。
- 导入：选择文件 → 解析并预览（各模块条目数）→ 明确告知「将覆盖当前数据」→ 确认 → 全量替换 → 页面刷新到首页。
- 侧栏底部「立即备份」是导出的快捷入口；长时间未备份时给文字提醒，不做自动备份、不弹窗打扰。

---

## 6. 本阶段明确不做（交互层面）

- 拖拽排序、批量选择、右键菜单
- 全局搜索、命令面板、标签体系的复杂筛选
- 多级页面、面包屑、页面返回栈
- 撤销栈（只保留删除后单次撤销）
- 复杂动画、页面转场、骨架屏、加载态
- 通知、提醒、桌面弹窗、系统托盘
- 任何需要联网才能完成的交互
- 打印、分享、多窗口同步
